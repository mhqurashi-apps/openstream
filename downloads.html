Read this first. The files below are working test builds, not a signed store release. Nothing is code-signed: Android warns about the APK, Windows SmartScreen warns about the MSI, macOS Gatekeeper warns about the disk image, and the iOS build has to be re-signed before a phone will run it. The SHA-256 next to each file is the one the build host measured.

Where to get them. No public binary host is configured yet, so these files are not downloadable from this page today. They sit in the build/packages/ directory of the build machine on the project network, next to the MANIFEST.txt they came from, and will be attached to the project's release page once one is published. Verify a file you downloaded

Put the file in a directory with MANIFEST.txt, open a terminal there, and run:

sed -n 's/^\([0-9a-f]\{64\}\)  [0-9]*  /\1  /p' MANIFEST.txt | sha256sum -c -

Every line ends in OK when the files are intact. One FAILED line means that file is corrupt or not the one this build produced — do not install it. Without the manifest, compare a single file against the table above:

sha256sum OpenStream-0.1.0-amd64.deb

Install, in plain language

Linux desktop client (.deb)

sudo apt install ./OpenStream-0.1.0-amd64.deb — apt resolves the GTK and libsecret dependencies. Start it from your application menu as OpenStream, or run openstream.

Linux host daemon (hostd .deb)

sudo apt install ./OpenStream-0.1.0-hostd-amd64.deb — this pulls in the FFmpeg runtime libraries the daemon links against. Then run openstream-hostd; it prints the pairing QR code and serves its metrics on 127.0.0.1:40075 and the session server on 127.0.0.1:40076.

Android client (.apk)

Copy the APK to the phone and tap it, or adb install OpenStream-0.1.0-android.apk. Android will ask you to allow installing from an unknown source: the build is debug-signed, not Play-signed.

Windows host daemon (.msi)

Double-click it. SmartScreen warns because the installer is unsigned. The Windows client is not in this build: it needs the MSVC toolchain and is produced by CI only.
